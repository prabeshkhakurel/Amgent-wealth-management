# Safe Links Configuration

## Objective

Protect users from malicious URLs by enabling Microsoft Safe Links.

## Configuration Steps

1. Open Microsoft Defender Portal.
2. Navigate to Email & Collaboration.
3. Select Safe Links Policies.
4. Create a new Safe Links policy.
5. Apply the policy to all users.
6. Save the configuration.

## Expected Outcome

- Malicious URLs are scanned.
- Users are protected from unsafe websites.

## Evidence Required

- Safe Links policy screenshot.
- Policy assignment screenshot.
