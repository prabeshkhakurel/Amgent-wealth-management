# Safe Attachments Configuration

## Objective

Protect users from malicious email attachments.

## Configuration Steps

1. Open Microsoft Defender Portal.
2. Navigate to Safe Attachments.
3. Create a new Safe Attachments policy.
4. Enable Dynamic Delivery.
5. Apply the policy.

## Expected Outcome

- Malicious attachments are detected.
- Unsafe files are blocked or quarantined.

## Evidence Required

- Safe Attachments policy screenshot.
- Testing screenshot.
