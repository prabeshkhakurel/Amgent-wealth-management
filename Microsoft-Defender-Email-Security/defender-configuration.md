# Microsoft Defender Configuration

## Objective

Configure Microsoft Defender for Microsoft 365 to enhance email security for Amgent Wealth Management.

## Implementation Steps

1. Sign in to the Microsoft 365 Defender Portal.
2. Review the existing security configuration.
3. Enable Microsoft Defender protection.
4. Configure baseline security recommendations.
5. Verify that Defender is active and protecting user mailboxes.

## Expected Outcome

- Microsoft Defender enabled successfully.
- Email threat protection activated.
- Security baseline applied.
- Configuration documented for future reference.

## Evidence Required

- Screenshot of Microsoft Defender dashboard.
- Screenshot of security recommendations.
- Screenshot showing successful configuration.
