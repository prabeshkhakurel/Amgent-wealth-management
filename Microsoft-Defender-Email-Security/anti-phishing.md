# Anti-Phishing Protection

## Objective

Protect users from phishing attacks and email spoofing.

## Configuration Steps

1. Open Microsoft Defender Portal.
2. Configure Anti-Phishing policy.
3. Enable Anti-Spoofing.
4. Enable Impersonation Protection.
5. Save the policy.

## Expected Outcome

- Phishing emails detected.
- Spoofed emails blocked.
- User protection improved.

## Evidence Required

- Anti-Phishing policy screenshot.
- Protection settings screenshot.
