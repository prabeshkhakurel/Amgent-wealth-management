# Microsoft Intune Implementation

**Assigned Team Member:** Sushil
**Project:** Amgent Wealth Management Cybersecurity Upgrade

## Objective

Implement Microsoft Intune device management and compliance controls to improve the security of Amgent Wealth Management devices.

## Responsibilities

- Device enrolment
- Device compliance policies
- BitLocker encryption 
- Secure Boot 
- Antivirus/security 
- Minimum operating system 
- Device compliance testing and validation

## Pre-Implementation Assessment

The existing Microsoft Intune environment was reviewed before making any changes.

Initial findings:

- Intune device inventory was reviewed.
- No managed devices were displayed during the baseline review.
- Existing compliance policies were reviewed.
- Endpoint Security returned an access unavailable/401 Unauthorized message during the baseline assessment.
- No configuration changes were made during the baseline assessment.

## Implementation Plan

1. Verify Microsoft 365 Business Premium licensing and required Intune access.
2. Confirm the client device meets the required specifications.
3. Enrol the approved device into Microsoft Intune.
4. Create and apply the required device compliance policy.
5. Configure BitLocker requirements.
6. Configure Secure Boot requirements.
7. Configure antivirus/security requirements.
8. Configure minimum operating system requirements.
9. Verify the device compliance status.
10. Test and document the results.
